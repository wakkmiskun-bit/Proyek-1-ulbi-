2. TUJUAN PENGEMBANGAN
Tujuan Umum & Target Luaran Khusus
Tujuan
TUJUAN UMUM
Mengembangkan platform TaskMate berbasis web untuk mempermudah pelacakan tugas mahasiswa secara visual menggunakan papan Kanban, serta mengotomatisasi pengingat via WhatsApp Gateway guna mencegah keterlambatan pengumpulan tugas di ULBI.
Luaran Khusus Mahasiswa
  • Workspace privat terisolasi per mahasiswa.
  • Notifikasi pengingat H-5 dan H-2 via WhatsApp (Manual).
  • Visualisasi alur Kanban yang interaktif.
Luaran Khusus Admin
  • Statistik performa real-time dasbor admin.
  • Live Monitoring Board Kanban mahasiswa.
  • Pencatatan jejak audit aktivitas (Audit Log).

3. MASALAH UTAMA
Identifikasi Permasalahan Utama
Masalah
Sisi Mahasiswa
  • Prokrastinasi & Forgetfulness: Sering menunda pekerjaan dan lupa deadline tugas.
  • Pencatatan Konvensional: Buku atau note fisik tidak memiliki pengingat otomatis.
  • Beban Prioritas: Kesulitan menyusun prioritas pengerjaan tugas akademik.
Sisi Pengelola (Admin)
  • Minim Monitoring: Kesulitan memantau progres kelulusan tugas mahasiswa secara nyata.
  • Penanganan Lambat: Deteksi dini mahasiswa yang mengalami penurunan performa sulit dilakukan.
  • Audit Trail Terbatas: Tidak ada catatan jejak log aktivitas penggunaan sistem.

4. TAMPILAN APLIKASI
Modul Antarmuka UI/UX (Clean & Glassmorphism)
Tampilan
Modul Sisi Mahasiswa
  • Dashboard Workspace: Menampilkan ringkasan data, progress bar persentase tugas selesai, kalender bulanan, & deadline feed.
  • Interactive Kanban: 4 Kolom status horizontal dengan drag-and-drop SortableJS & navigasi tombol cepat.
  • Profil & Bantuan: Unggah foto profil baru (Max 2MB) & link API chat WhatsApp ke admin.
Modul Sisi Administrator
  • Dashboard Analytics: Menampilkan ringkasan total mahasiswa, total tugas terbuat, dan tugas selesai.
  • Live Monitoring Board: Admin dapat melihat dan mengelola Kanban Board mahasiswa secara live.
  • System Audit Logging: Menampilkan riwayat log aktivitas yang dilakukan mahasiswa di platform.

6. ALUR KERJA APLIKASI
Alur Kerja Sistem & Layanan Pusat Bantuan
Alur Kerja
Alur Kerja Operasional
  • Registrasi & Login: Kredensial nim & phone, password Bcrypt aman.
  • Input Tugas Baru: Isi form -> Submit via AJAX POST -> Status 'TO DO'.
  • Kanban & Auto-Done: Drag & drop kartu. Checklist 100% otomatis geser ke Done.
  • Pengiriman Pengingat Manual: Administrator memicu command Artisan PHP untuk kirim pengingat tugas H-5 & H-2 via Fonnte API.
Bantuan Hubungi Admin
  • Pusat Bantuan Mahasiswa: Akses menu Bantuan kapan saja langsung dari dashboard personal mahasiswa.
  • Direct WhatsApp API Link: Tombol khusus untuk langsung chat ke nomor WhatsApp Admin ULBI.
  • Respon Cepat Technical Support: Membantu verifikasi bug, reset password, atau konsultasi kendala sistem lainnya secara real-time.
